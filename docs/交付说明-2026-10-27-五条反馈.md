## 1. 反馈 ② 详情：线上 500 的根因

```sql
-- prisma/migrations/20261013170000_b1_drift_fix/migration.sql
MODIFY COLUMN `snap_key` VARCHAR(80) NOT NULL;
ADD UNIQUE KEY `uk_snap` (`snap_key`);
```

`snap_key` 无默认值。旧代码两处 `tx.db.insert('memoryArchive', {...})` 都没带它：

```ts
await tx.db.insert('memoryArchive', { id, familyId, year, type: 'TRIP', refId, snapshotJson, createdAt });
```

MySQL 严格模式 → `Field 'snap_key' doesn't have a default value`（1364）→ 事务回滚 → 信封 `服务内部错误`。

**修法**（`apps/server/src/domains/memory/memory.service.ts`）：

- TRIP：`snapKey = 'T:<tripId>'`
- ANNUAL：`snapKey = 'A:<familyId>:<year>'`
- 幂等查询从 `(familyId, year, type)` 改成按 `snapKey` —— 因为 v1.4 迁移已经把
  `memory_archive_family_id_year_type_key` 删掉了，按旧条件查会把「同一年第二场出行」
  误判成"已存在"，直接返回别的行程的快照。改成 `snapKey` 后一年多次出行各一篇。

**回归用例**：`apps/server/test/memory-generate.test.ts`（5 条，全绿）
内存驱动下断言 `snapKey` 确实被写进行里 —— 这是把 DB 的 NOT NULL 约束提到应用层，
补上"测试绿、线上红"的口子。

## 3. 反馈 ③：预算 + 清单分两类

### 3.1 预算（`trip.budget_minor`）

- 口径：**最小货币单位整数**（分），与 `expense.amount_base` 同源 —— 一边元一边分是最常见的差 100 倍 bug。
- `NULL` = 未设预算。界面不显示 0%、不显示「还剩 0 元」，只给「设置预算」入口。
- 展示：预算 / 已花 / 剩余（超支转红）/ 进度条 / 剩余 N 天日均可用。
- 写入复用 `PATCH /trips/:id` 的 CAS（`version` 必传），保存后外层重拉行程。

### 3.2 清单分两类（`trip_checklist_item.kind`）

- `TODO` = 要做的事（订票、办证、给猫找寄养）
- `PACK` = 要带的东西（身份证、充电宝 x2）
- 清单 tab 变成**两个分区 + 两条独立进度条**；添加时先选类型再选可见范围。
- 默认 `PACK`：历史数据全是打包物品，且老客户端不传该字段。

## 10. 修订（2026-10-27 18:30）：反馈④的层级做错了，重做

上一版把「我的常备物品」做成了与「家庭清单 / 我的清单」**平级**的第三段 —— 方向错了。
用户的原话：

> 「家庭清单或者个人清单都要根据类型分类，也就是常备物品其实就应该包含家庭清单和我的清单。」

### 10.1 正确层级

```
常备物品（上位概念）
├─ 家庭常备 · 全家可见   → checklist_template (scope = SHARED)
└─ 我的常备 · 仅自己可见 → checklist_template (scope = PERSONAL)
      └─ 每个条目带「类型」，按类型分组展示
```

`item` 表那套（第二套模型）不再出现在界面；旧数据用页内一次性「并入」按钮复制过来，
**原行不删**（`outfit_item` 外键仍引用，删了回不去）。

### 10.2 条目类型（category）

- 存储：`checklist_template.items_json` 的数组元素多一个 `category` 字段，**无需 DB 迁移**；
- 校验：create / update 两处 Zod 放行 `category`（不锁枚举，家庭自建分类如「露营」不被拒）；
- 归一化：`parseTemplateItems`（前后端各一份）只接受非空字符串，其它形态丢弃 ——
  否则会分出一个「名称为空」的类别；
- 展示：按 `ITEM_CATEGORIES` 顺序分组，自定义分类居中，「未分类」垫底；每组带件数；
- 录入：粘贴一整段时，整段归到当前选中的类型下（避免贴完再逐条补）。

### 10.3 文案统一

`长期清单` / `物品清单` / `物品库` 三个叫法全部收敛为「常备物品」：
页面副标题「常备物品：家庭一半，我的一半」、内层 tab「常备物品」、
管理入口 hint「家庭一半 / 我的一半」。
