> **唯一真实来源**：本文档是用例的权威定义。执行状态只记在 `qa/tracking/执行追踪.csv`，两边不一致时以本文档为准。
> **基线**：《需求概要-家庭出行计划》v1.3（已锁定决策）+ 客户端 `apps/client` 2026-10-22 提交 `52d246e`
> **格式**：Google AAA —— 每个用例必须写清 准备(Arrange) / 执行(Act) / 断言(Assert)，任何人照着能复现。
> **环境**：`ENV-H5-MOCK`（Mock 数据源，无头 Chrome 390×844）、`ENV-H5-LIVE`（连本地后端 :3000）、`ENV-WX-DEV`（微信开发者工具，基础库需与 `project.config.json` 的 libVersion 一致）

## 0.1 优先级定义

| 级别 | 含义                                   | 响应时限    |
| ---- | -------------------------------------- | ----------- |
| P0   | 核心链路中断、数据丢失、越权/隐私泄露  | 24 小时内修 |
| P1   | 主要功能不可用或结果错误，有绕行成本高 | 48 小时内修 |
| P2   | 功能缺失或与需求不符，但有替代路径     | 本迭代修    |
| P3   | 体验/口径/展示问题                     | 排期修      |
| P4   | 文案、细节打磨                         | 有空再修    |
