## A1. 开通云硬盘自动快照（5 分钟，最先做）

**为什么最先**：这台机器上是 XLFamily + FamilyTrip 两个项目的唯一副本，盘一坏双丢，快照是唯一保险。

**步骤**：

1. 浏览器登录 **cloud.tencent.com** → 右上角控制台 → 左侧「轻量应用服务器」→「**服务器**」→ 实例列表点 **lhins-lhvlecwc**（Ubuntu-F0ak）
2. 实例详情页找「**快照**」标签 → 先点「**创建快照**」手动创建一个（弹窗里快照名称用默认的即可，点确定；通常 5 分钟内完成）——**这一步同时验证链路能通**
3. 回快照列表页找「**自动快照策略**」入口（若该版本无此入口，见下方兜底）：
   - 策略名称：`family-trip-weekly`
   - 执行时间：**每周**一次（如周一 03:00，凌晨低谷）
   - 保留数量：**2 个**（滚动删除最旧，总量恒定 ≤2）
4. 关联到本实例

> 🔴 **配额纪律**：轻量免费快照配额 = 实例数 × 2（最多 20 个），你当前只有 **2 个免费额度**。
> 所以快照策略必须「每周 + 总量 ≤2」——**绝不能按天**，按天第 3 天就开始超额计费。
> 超额部分费用虽低，但没必要花；回滚深度用 2 个快照覆盖「本周 + 上周」也够用。
>
> **⚠️ 实际验证结论（2026-10-19）**：该账号的轻量控制台**没有自动快照策略入口**（已截图确认，
> 左侧导航与实例详情快照页均无此项）。实际方案：每周由 WorkBuddy 自动化代创建
> （attempt → 成功建/失败发提醒，不存在静默失败），满 2 个时提醒 Kira 手动删最旧。
> 若自动化不可用，退化为每周一手动创建 + 日历提醒——共机生产宁可麻烦不可裸奔。

**验收**：快照列表出现一条「创建中/已完成」的手动快照 + 策略显示已关联。

## A2. ICP 备案（周期最长，今天就启动）

**去哪**：cloud.tencent.com → 控制台 → 搜「备案」→ 进入备案管理系统（或直接访问备案入口页）。
**注意**：服务器在北京（ap-beijing-3），备案由**北京市通信管理局**终审。

**步骤**：

1. **域名实名**（前置，未实名备案系统不让你进）：
   - 你的域名在哪个注册商（DNSPod/阿里云/腾讯云）→ 该平台 → 域名管理 → 实名认证 → 传身份证正反面 → 等审核（一般 1 个工作日内）
2. **申请备案服务号**：备案系统 → 关联云资源 → 选择轻量服务器 lhins-lhvlecwc → 申请备案服务号（每个云资源有配额，申请即得）
3. **填写主体信息**（个人备案）：
   - 主体类型选「个人」；填你的姓名、身份证号、手机号、邮箱
   - 通讯地址按身份证地址或现居址（能收快递的地址，部分地区要核验单）
4. **填写网站信息**：
   - 网站名称：如「家庭出行计划」（个人备案名称有词类限制，别用「平台/中心/中国」等词）
   - 域名：你打算用的 API 域名（如 `api.你的域名.com`）
   - 服务内容：按实际选（工具/查询类，没有完全匹配就选最接近的，备注写明「家庭出行小程序 API 服务」）
5. **上传材料 + 核验**：
   - 身份证正反面照片（四角齐全、不反光）
   - 人脸核验：腾讯云 APP / 小程序活体检测（按提示眨眼摇头，1 分钟）
   - 部分省份要求下载「网站备案信息真实性核验单」打印签名后拍照上传（系统会提示，北京近年多为电子化，按提示来）
6. **提交后三段审核**：
   - 腾讯云初审（1–3 个工作日，材料不对会打回，保持手机畅通）
   - **工信部短信核验**：负责人手机会收到 5 位验证码短信，**24 小时内**到工信部网站填码（这一步漏了直接失败，收到马上做）
   - 管局终审（7–20 个工作日）
7. 备案通过后控制台显示备案号（格式：京ICP备xxxxxxxx号）

**验收**：拿到备案号；备案系统状态显示「已备案」。

## A3. 创建 2G swap（5 分钟）

**去哪**：腾讯云控制台 → 轻量服务器 → 实例 → 右上角「**登录**」→ 选 **OrcaTerm**（浏览器终端，免 SSH 密钥，最稳）。
**登录账号**：`ubuntu`（镜像默认管理员；若 OrcaTerm 直接进了 root/ubuntu 会话，按提示来）。

**步骤**：登进去后逐条粘贴执行：

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h
pm2 list
```

**验收**：`free -h` 输出里 Swap 行显示 `2.0G`；`pm2 list` 能看到 `family-space` 在跑（确认共机现状，**不要动它**）。

## A4. 获取 WECHAT_SECRET（10 分钟）

**去哪**：**mp.weixin.qq.com** → 用小程序管理员微信**扫码**登录（注意：是管理员账号，普通运营者扫码看不到 AppSecret）。
**入口**：左侧「开发管理」→「开发设置」。

**步骤**：

1. 开发设置页找到「**AppID**」：核对是不是 `wx3567e523d83206e4`（不是就停下，说明登错账号或拿错小程序）
2. 「**AppSecret**」栏点「**重置**」→ 微信扫码确认 → 页面显示新的 AppSecret（只完整显示这一次）
3. **立刻复制**存进你的密码管理器（Bitwarden/1Password/备忘录加密均可）
4. 同页检查「**IP 白名单**」（如有配置项）：把服务器公网 IP `82.156.30.50` 加进去——没配就是不限制，跳过
5. 顺手记录同页的「request 合法域名」入口位置（A6 还要来）

**纪律**：AppSecret = 小程序身份凭证，**不要截图、不要发微信/QQ、不要贴任何聊天窗**。泄露处置是重置，但泄露期间别人能用你的小程序身份调微信接口。

**验收**：密码管理器里有一条记录（名称建议 `FamilyTrip-WECHAT_SECRET`），页面显示重置成功。

## A5. 生成 JWT_SECRET（2 分钟）

**去哪**：本机 **Git Bash**（开始菜单搜 Git Bash）。
**步骤**：

```bash
openssl rand -base64 48
```

把输出的一整行（类似 `aB3x...==`）复制，存进密码管理器（记录名 `FamilyTrip-JWT_SECRET`）。

**验收**：密码管理器多一条记录。**不要发给我**——部署时你自己按 DEPLOY.md 粘进 ecosystem 配置；万一要让我帮你排障，用「占位描述」而不是真实值。

## A6. 配 request 合法域名（5 分钟，放在 A2 备案完成后）

**去哪**：mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名 → 「**request 合法域名**」。
**前置**：A2 备案已通过 + 域名证书已部署（派发单 D12，backend-architect 指挥完成）。

**步骤**：

1. 点「开始配置」→ 添加 `https://api.你的域名`（只填到域名级，不带路径；必须是 https）
2. 保存后微信会校验域名备案状态（已备案则直接通过）
3. 确认保存成功（列表里能看到该域名）

**注意**：合法域名有**月修改次数限制**，一次填对，别拿测试域名反复试。另外小程序代码里的 API 基址（派发单 D7）必须指向同一个域名，两边一致才通。

**验收**：合法域名列表显示 `https://api.你的域名`；微信开发者工具里小程序能调到 `/health`。

## 通用纪律（适用于所有项）

1. **凭证三不**：不截图、不发聊天工具、不落非密码管理器的文件。所有 secret 只进两个地方——密码管理器、pm2 ecosystem 配置。
2. **顺序纪律**：A1 → A2（立刻启动）→ A3/A4/A5（随时）→ 等部署就绪 → A6 → A7。A2 的 7–20 个工作日是全程唯一的长周期，其他都加起来不到一小时。
3. **共机红线**：A3 之后任何时候登服务器，`pm2 list` 里看到 `family-space` 就是 XLFamily——不 stop、不 delete、不改它的 ecosystem。
4. **卡住就停**：页面对不上、审核被驳回、命令报错——停下来截图给 backend-architect，不要连环尝试。
